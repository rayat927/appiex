Frequently Asked Questions

How does automated MikroTik reconnection work when a user pays via bKash or Nagad? +

When a subscriber completes payment via bKash or Nagad, the payment gateway sends an instant cryptographic webhook to our backend. The system marks the invoice paid, logs the transaction in PostgreSQL, and triggers a MikroTik RouterOS API command to re-enable the user's PPPoE profile or queue within seconds.

Questions for an ISP billing software project

Before replacing a billing platform, map the full subscriber lifecycle: activation, plan changes, suspension, payments, reconnection and technical support. Plan data import and reconciliation so mismatches do not lock out paying customers.

  • Router integration: confirm supported MikroTik versions, authorization and fallback behavior.
  • Billing and payments: define invoices, renewal rules, gateways, reconciliation and manual corrections.
  • Operations: customer portal, backups, roles, audit logs and staff handover.
